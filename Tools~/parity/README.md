# Паритет симуляции с редактором

Сравнивает C#-порт симуляции (`Runtime/Core`) с оригинальным `js/core` редактора
Arcaidia Effector на всех эффектах его `library/`. Нужны Node 18+ и .NET SDK 8+.
Unity не нужен: ядро не зависит от UnityEngine.

```bash
# 1. дамп состояния частиц оригинальным движком (24 точки времени на эмиттер)
node dump.mjs "<путь к редактору>/Arcada Effects" js.txt

# 2. тот же прогон C#-портом и сравнение
dotnet run -c Release -- "<путь к редактору>/Arcada Effects/library" js.txt
```

Ожидаемый результат: `countMismatch=0`, `maxRelErr` порядка 1e-10 (последние биты
`Math.sin/exp`/`atan2` в V8 и .NET различаются). Код возврата 0 — паритет есть.

Любой `COUNT ...` — расхождение логики (порядок вызовов rng, условие рождения/гибели,
дефолт поля в модели): искать по первой строке.
